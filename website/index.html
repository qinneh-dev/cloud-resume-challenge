The Cloud Resume Challenge Active

A full-stack, multi-region web application and automated DevSecOps pipeline architected from the ground up to run 100% within the AWS Free Tier ($0/month operational footprint), demonstrating cost-conscious cloud-native infrastructure design.

  • Serverless & Zero-Cost Backend: Routed traffic via an AWS HTTP API Gateway to a Python 3.10 Lambda function running on ARM64 Graviton2 compute, utilizing atomic DynamoDB expressions to handle high-concurrency visitor counting without incurring database read/write capacity charges.
  • IaC & Zero-Trust Edge: Provisioned all multi-region AWS infrastructure declaratively using Terraform. Sealed the static S3 frontend against public internet exposure, serving traffic securely through an Amazon CloudFront distribution with Origin Access Control (OAC).
  • CI/CD & Orchestration: Automated continuous deployments via GitHub Actions using a self-hosted EC2 runner configured automatically with Ansible playbooks within Free Tier compute limits. Backend services are containerized with Docker and orchestrated locally using K3s Kubernetes manifests.
